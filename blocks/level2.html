Level 2 blocks#

M - Wireless MBus packet#

This block format describes payloads that have been received via the Wireless MBus modem. The UID from the MBUs packet format can be used to uniquely identify the instrument that has sent the data.

The M block format has a ‘wrapping’ property in that the L1 blocks it describes are surrounded by data from the L2 block. This is because the RSSI byte is appended on to the transmitted L1 message by the Wireless MBus modem and we are avoiding manipulating the bitstream in the processing chain.

R - Receiver sensors#

This block format indicates that the payload of sensor data originates from sensors directly connected to the reporting device (which is described by a parent L3 block). As an example, the datalogger can report environmental variables (temperature, humidity, etc.), orientation and system power status using the E, B and V L1 blocks which describe parameters of the datalogger itself rather than the any instrument received by it.
