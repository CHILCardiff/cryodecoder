API: cryodecoder#

Submodules#

Functionality of the cryodecoder module is split into several submodules. The blocks submodule defines the blocks and subblocks which make up CHIL packets and provides an interface to parse and interact with them. The parser submodule provides defines a parsing algorithm for CHIL data and various interfaces to parse and log data from files and USB data streams. The cloudloop submodule provides functionality to list and download packets from the IOT provider Cloudloop.

Top-level functions#

There are several ‘utility functions’ in the top level of the cryodecoder module.

cryodecoder.parse_hex(hex_input: str)#

Parse CHIL data from hexadecimal strings.

Parameters:

hex_input – String encoding binary data in CHIL format.

Returns:

Ordered list of the decoded blocks from the string

Return type:

list[cryodecoder.blocks.Block]

cryodecoder.download_and_parse_cloudloop(raw_path: str | PathLike, data_path: str | PathLike, start_date: DateLike | None = None, end_date: DateLike | None = None, request_params: dict | None = None, api_key: str | None = None, api_root: str = 'https://api.cloudloop.com', disable_progress_bar=False)#

Download data from Cloudloop to a .csv file and decode CHIL data from any messages into a separate .csv file.

Parameters:

  • raw_path – Path for the raw data and metadata from Cloudloop to be downloaded to.

  • data_path (str or PathLike) – Path for the parsed CHIL blocks to be written to in .csv format.

  • start_date (Optional[DateLike]) – (optional) Messages received after this value will be downloaded.

  • end_date (Optional[DateLike]) – (optional) Messaged received before this value will be downloaded. If not supplied, it defaults to the current time in UTC.

  • request_params (Optional[dict]) – (optional) Additional parameters to be suppled in the HTTP request.

  • api_key (Optional[str]) – (optional) The API key associated with your Cloudloop account. If no api_key is provided, then the function will check for environment variable “CLOUDLOOP_API”.

  • api_root (str = DEFAULT_API_ROOT,) – (optional) If another server is used to host the Cloudloop API then the root URL can be changed with this parameter.

  • disable_progress_bar (bool) – (optional) Set to True to disable the CLI progress bar while downloading takes place.

Type:

raw_path: str or cryodecoder.blocks.PathLike

Returns:

Ordered list of the decoded blocks from the string

Return type:

list[cryodecoder.blocks.Block]
