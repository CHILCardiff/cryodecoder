class cryodecoder.parser.Parser(async_input: bool = False)#

The Parser object implements the logic to decode CHIL instrument packets and previous versions.

The Parser object is used by FileDecoder and SerialDecoder to read packets logged to CHIL dataloggers and transmitted over USB serial links. Parsing logic is separated into four main ‘states’ which are readIdentifier, readLength, readField and appendBlock.

Note

TODO: Add separate documentation page describing the parser logic and state diagram.

Example usage to parse bytes into cryodecoder.block.Block objects.

# Define some input data
input_data = b"C\x07\x01<\x0f\x8c\x0f\x80\x0c"

# Create a parser object
parser = cryodecoder.parser.Parser()

# Send the data to the parser
parser.push(input_data)

# Run the parser until it is has finished processing
while not parser.complete():
    parser.update()

# Extract valid data
timestamp, block = parser.read()
Parameters:

async_input (bool) – set to True if bytes are expected to be delivered asynchronously (i.e. over a USB decoder). Defaults to False.

reset_stack_variables()#

resets the internal state variables that implement the parser logic.

push(raw: bytes)#

appends bytes to the end of the FIFO buffer

Parameters:

raw (bytes) – the bytes to append to the buffer

pop(count: int = 1)#

removes bytes from the beginning of the FIFO buffer

Parameters:

  • count – number of bytes to remove, defaults to 1.

  • type – int

complete()#
Returns:

True if the parser has finished interpreting the input bytes, otherwise returns False. Always returns False if the Parser has been initialised in asynchronous mode.

Return type:

bool

available()#
Returns:

the number of blocks available that have been parsed but not read

Return type:

int

read() → tuple[datetime, Block] | None#

This method is used to access the CHIL blocks that have been read from the binary data by the parser object. :return: a tuple containing the time at which the block was read and the block object itsellf :rtype: tuple(datetime.datetime, cryodecoder.blocks.Block) or None if no blocks are available.

update()#

Calling the update method runs the parsing logic associated with the current state. It then updates the state based on the outcome of that logic.

class cryodecoder.parser.MBusDataFormatter(column_name: str)#

Extends the DataFormatter class to be used specifically for fields contained with MBus packets.

If a Level 2 or Level 3 block is used as the argument to getFormattedValue() then it will apply the formatting to the child cryodecoder.blocks.Block_M_MBusPacket block if one is available.

To ensure backwards compatibility with pre-2026 packet formats, two methods are implemented:

  • getMBusValue() for blocks in the 2026 packet format.

  • getReceiver2023Value() for legacy packets.

Parameters:

column_name (str) – the name associated with the field being formatted

getFormattedValue(block)#

Selects the appropriate method from getMBusValue() and getReceiver2023Value(), applies the appropriate formatting to the MBus sub-block and returns the formatting value.

class cryodecoder.parser.SerialDecoder(port: str = 'COM1', baud_rate: int = 19200, file_root: PathLike | None = None, mode: Literal['receiver', 'mbus'] = 'receiver')#

The SerialDecoder class provides an interface to decode realtime packets transmitted from a CHIL datalogger over a USB serial connection.

Example usage:

# Create a SerialLogger on COM10 with a 19,200 Hz baud rate and saving
# in a subfolder of the current directory
logger = SerialLogger("COM10", file_root = "./my_logger_data")
logger.run()
Parameters:

  • port (str) – identifier of the COM port

  • baud_rate (int) – the baud rate of the serial connection, defaults to 19200

  • file_root (Optional[PathLike]) – path to where packets should be saved in CSV format.

  • mode (str) – sets whether a CHIL datalogger (“receiver”) or Radiocrafts MBus receiver (“mbus”) is being used as the USB receiver.

# in a subfolder of the current directory

)
